Frequently asked questions

What to know before converting a file.

Is ConvertHub free?

This prototype is designed around free tools supported by advertising. Real hosting and heavy conversions may create operating costs.

Can I convert PowerPoint to PDF?

The tool is included in the catalog. Reliable PPT/PPTX-to-PDF conversion requires a configured document-processing engine, such as LibreOffice running on a suitable backend.

Why are some tools not available yet?

Some conversions require server-side software, including LibreOffice, FFmpeg, or OCR engines. This single HTML file cannot safely replace those services.

Are my files stored?

This interface does not upload files to a server by itself. Once a backend is connected, its retention and deletion behavior must be implemented and documented accurately.

Can I use it on my phone?

Yes, the interface is responsive and supports the mobile file picker. Processing capabilities depend on the selected tool and device.
